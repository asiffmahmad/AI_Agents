# Documentation Standards

All AI-generated documentation MUST follow these strict formatting guidelines:

1. **Format:** Use strict GitHub Flavored Markdown (GFM). Ensure clear hierarchies using H1, H2, and H3 headers.
2. **Visualizations:** Use **Mermaid.js** syntax to generate Flowcharts, Sequence Diagrams, Architecture Diagrams, and ER Diagrams where appropriate to visualize complexity.
3. **Traceability:** Maintain strict traceability matrices within major documents linking: Business Goal → Requirement → User Story → Technical Task → Test Case.
